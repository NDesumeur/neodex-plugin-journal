# Journal

Un journal intime, une page par jour : écris ce que tu as vécu, note ton humeur, et retrouve tes anciennes pages dans un calendrier coloré selon tes humeurs.

*English version: [README.en.md](README.en.md)*

## Écrire

- La page du jour s'ouvre directement : écris dans le grand champ (« Comment s'est passée ta journée ? »). Tout est **enregistré tout seul** pendant que tu tapes ; l'en-tête indique l'heure de la dernière modification.
- **Humeur** : choisis de 1 à 5, de « Très mauvaise journée » à « Super journée ». Un nouveau clic sur la même humeur l'efface.

## Relire

- Le **calendrier** montre le mois, les semaines commençant le lundi. Les jours écrits sont marqués de la **couleur de ton humeur** ; aujourd'hui est encadré.
- **Clique un jour** pour lire ou compléter sa page, même un jour passé que tu avais oublié.
- Les flèches changent de mois ; **Aujourd'hui** revient au jour présent.

## Statistiques

Sous le calendrier : le nombre de jours écrits ce mois-ci, le total de pages, et ta **série** de jours écrits d'affilée (elle compte jusqu'à hier si tu n'as pas encore écrit aujourd'hui).

## Données et synchronisation

Tes pages et tes humeurs sont enregistrées par NeoDex, sauvegardées et synchronisées entre tes PC si la synchro est activée. Elles ne sont envoyées nulle part ailleurs.

## Installer

Dans NeoDex : **NeoStore → À découvrir → Journal → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
